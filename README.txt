狼人杀 · 人类玩家四局关系回放

打开 狼人杀_人类玩家关系回放.html（或原H1文件）即可离线使用，无需安装或联网。
dist/ 是同一页面的分文件版本，供本地服务器或私有站点使用。

操作
- 12人按座位号顺时针固定排列，出局后保留座位并显示叉号。
- 顶部选择第一/三/六/八期第一局，各局独立座位和时间线；AI数据尚未接入。
- 初始画面是所选局第1天每日快照；点击“从头播放”回放完整过程。
- 时间线可拖动，也可用上一段/下一段、播放/暂停与倍速。
- 白天按钮按所选局动态生成（3/5/4/5天）；没有实际投票的日子不编造票型。
- 时间线“警长竞选”“选警结果”可直达竞选开始和主持宣布结果。
- 图上方的“警长竞选”可展开参选、退水、选警票型和本日归票；时间按钮可核对原话。
- 竞选期间节点标注参选/退水，11号当选后持续标注警长。向前回放不提前显示结果。
- 支持为绿实线、怀疑为红虚线、投票为蓝点线，可分别开关。
- 点击玩家查看发出/收到的关系；点击连线或证据列表查看原话。
- “赛后视角”默认关闭，开启后区分已确认、推定和未知身份。
- 图可滚轮缩放、拖动平移；支持导出SVG及当前可见边表。
- 页面空白处的空格播放/暂停，左右方向键逐段；控件保留原生键盘操作。

数据口径
- H1保留原有研究表格及94条快照边；H3/H6/H8来自新增逐字稿的完整语义注释。
- 新增局只有夜间/终局公告而没有公开讨论的白天标NA_NO_DISCUSSION，不当作观测零值。
- H3/H6/H8的存活状态按公开事件推进，当前在场玩家形成身份关系网络；真实投票保留记录。
- 注释与完整研究文件位于datasets/human/；可按原话复核，视频不纳入repo。
- dist/campaign-events.js补充4条可追溯的公开退水事件；它们不生成支持或怀疑边。7/10/12号依据本人发言，8号依据08:36主持汇总；08:34说话人保持未确认。
- 同日按最后一次明确立场更新；跨天不自动继承。
- 未定立场移除该对当前连线。条件句、回顾、引用与行动建议不自动生成边。
- 访谈、回放、赛后片段不进入公共回放。遗言可阅读，不更改投票前快照。
- 选警票和放逐票分别展示，发生新票型后替换，不叠加票型。
- 第2天11号漏报票保持未知；最后8号疑似自投保留核查说明，不绘制自环。
- AI辅助首轮编码，部分语义与说话人映射仍待人工复核。
- 赛后身份开关仅影响元数据标签，原发言中的角色声称仍保留原文。

实现
D3.js 7.9.0随文件保存，依据其ISC许可使用，库文件保留作者版权声明。
使用Node内置测试运行器验证逐日快照、回退重建、跨天重置、未知票型、身份隐藏和警长竞选事件。
