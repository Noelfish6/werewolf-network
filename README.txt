狼人杀 · 关系回放

打开 H1_狼人杀互动关系图.html 即可离线使用，无需安装或联网。
dist/ 是同一页面的分文件版本，供本地服务器或私有站点使用。

操作
- 12人按座位号顺时针固定排列，出局后保留座位并显示叉号。
- 初始画面是第1天投票前快照；点击“从头播放”回放完整过程。
- 时间线可拖动，也可用上一段/下一段、播放/暂停与倍速。
- 三个白天的按钮跳到各天投票前快照。
- 支持为绿实线、怀疑为红虚线、投票为蓝点线，可分别开关。
- 点击玩家查看发出/收到的关系；点击连线或证据列表查看原话。
- “赛后视角”默认关闭，开启后区分已确认、推定和未知身份。
- 图可滚轮缩放、拖动平移；支持导出SVG及当前可见边表。
- 页面空白处的空格播放/暂停，左右方向键逐段；控件保留原生键盘操作。

数据口径
- 数据来自现有H1_SNA表格，原始分析数据未修改。
- 同日按最后一次明确立场更新；跨天不自动继承。
- 未定立场移除该对当前连线。条件句、回顾、引用与行动建议不自动生成边。
- 访谈、回放、赛后片段不进入公共回放。遗言可阅读，不更改投票前快照。
- 选警票和放逐票分别展示，发生新票型后替换，不叠加票型。
- 第2天11号漏报票保持未知；最后8号疑似自投保留核查说明，不绘制自环。
- AI辅助首轮编码，部分语义与说话人映射仍待人工复核。
- 赛后身份开关仅影响元数据标签，原发言中的角色声称仍保留原文。

实现
D3.js 7.9.0随文件保存，依据其ISC许可使用，库文件保留作者版权声明。
使用Node内置测试运行器验证逐日快照、回退重建、跨天重置、未知票型和身份隐藏。
