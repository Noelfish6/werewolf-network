# 四局人类玩家数据与关系回放

用户已提供三局新逐字稿，要求沿用H1处理方式并加入现有可视化；AI材料暂不处理。游戏ID按期数为H1/H3/H6/H8，各局座位和昵称独立，不跨局继承。

沿用原文保留、精确引文、逐白天支持/怀疑/投票分层、身份确认/推定/未知及可追溯核查清单。三局分别进行完整语义编码，共135/97/104段，不能靠关键词自动抽边。条件、集合、回顾、逻辑认可、投票提议与访谈不进入明确身份关系。提供CSV、JSON、矩阵、GraphML和工作簿，来源哈希可验证。

界面在顶部增加人类对局选择器，动态显示各局的白天数量、总时长、玩家、竞选过程；沿用同一个圆形网络、证据栏和逐段时间线。相比每局另做一个页面，统一选择器方便检查；暂不做跨局合并网络，因为同一座位不是同一玩家且用户未要求汇总分析。

切局时暂停并重置焦点、关系选择、身份揭示、缩放和回放位置；图层偏好保留。新增局支持4–5天、自爆、技能死亡和无投票的白天，不编造票型。终局同段旁白的身份揭示由赛后开关控制，公开票型与游戏结果仍可读。

新增局的存活状态按已公开死亡事件推进，避免用投票前生存表提前泄露死亡；关系网络显示当前在场玩家的最新明确立场。H1保留现有研究快照与既有回放口径。源逐字稿不改写，视频不加入repo，AI类别不接入。
