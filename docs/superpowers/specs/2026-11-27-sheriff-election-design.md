# 警长竞选信息展示

用户需要看清警长竞选如何影响这一整局互动。已有竞选发言、选警票、参选名单及当选记录，缺少可见的过程摘要。

采用图上方的紧凑信息栏，默认收起详细名单；展开后查看参选、退水、最终候选与票型，并可跳转原话。节点在竞选期间标注参选/退水，当选后持续标注警长。时间线提供竞选开始、选警结果两个入口。

相比新增第四种关系图层，过程栏能表示无方向的参选/退水状态；相比只在说明里补充，过程栏随回放更新且更容易发现。选警票仍由现有投票层控制，不自动视为身份支持。

按观察到的发言顺序揭示，向后拖动必须撤回未来信息。7、10、12号的明确退水各有本人原话；8号仅在08:36主持汇总时确认，不把08:34未识别说话人指定为8号。结果显示11号3票、1号1票、3号0票、4号弃票；其余为无投票资格。沿用现有D3与离线构建，不新增依赖。
